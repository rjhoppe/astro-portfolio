It seems that only the most extreme takes on AI ever generate any attention in the public space. I try to stay off "tech twitter" (and all x/twitter for that matter) as much as possible, but the algorithm has rightfully determined that I enjoy reading developer adajacent content. So despite my best efforts, I find myself subjected to the hottest of hot AI takes on both ends of the spectrum. 

I would like to provide a fairly lukewarm take on how using AI tools has made me a better developer. 

I try to use AI tools as much as possible (within reason) on personal projects outside of work. I think it's fun trying out all these different tools and it has enabled me to increase my output on my projects. But one of my favorite things about being a developer is learning something new almost everytime I put my hands to keyboard. So naturally, when I ask the AI to help me implement something, it becomes a conversation. I ask why it is using a certain syntax, why it needs to perform that validation, what that library function it is using does... I want to understand the approach. Even on personal projects, I like to know what all the code the AI has does. 

I have found that this approach of turning AI assisted coding into AI assisted collaboration has made me a substantially better code reviewer at work. I review code written by people the same I review code written by AI. 


I think it's easy for the black and white takes on AI to bubble to the surface.
